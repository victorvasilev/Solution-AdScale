**API gateway**

Запросы, отправляемые через API Gateway осуществляются по следующему сценарию. Переход к следующему шагу возможен при успешном прохождении текущего шага:
1. Проверка на rate limiter
2. Аутентификация и авторизация пользователя
3. Маршрутизация запросов в bidding-service. Если он недоступен - применение circuit breaker pattern с возвратом default-значений для read-операций.

К API Gateway подключен мониторинг Prometheus, на дашборды выведены графики со средним временем отклика и максимальным за период. Настроен alert'инг при достижении 90% показателя от максимально возможного времени ответа согласно требованиям.
