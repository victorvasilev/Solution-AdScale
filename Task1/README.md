**Задача**

Данный набор артефактов создаётся для решения задачи компании AdScale по интеграции с крупной DSP-площадкой, в результате чего нагрузка на сервис возрастёт в виду увеличения количества пользователей.
Сервис нуждается в изменении архитектуры для возможности обрабатывать примерно 18 000 RPS.

Если ничего не менять, возникает риск деградации времени отклика свыше 150 ms, сбоев в работе модуля ставок, проигрыша аукционов, финансовых штрафов от DSP-партнёра, репутационных потерь и невозможности обслуживать текущих клиентов.
